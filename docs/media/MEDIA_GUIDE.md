# Media checklist

Add exactly these selected files to this directory before committing:

1. `01_simulation_overview.png` — wide Gazebo view showing the Panda, table, and bottle.
2. `02_vision_detection.png` — camera/OpenCV view showing the detected bottle and coordinates.
3. `03_grasp_and_lift.png` — clear side-grasp or lifted-bottle frame.
4. `04_continuous_shake.png` — strongest frame from the final continuous shake.
5. `05_complete_pick_shake_place.mp4` — trimmed complete demonstration.

Recommended media rules:

- Use 16:9 screenshots where possible.
- Crop terminal clutter and unrelated desktop content.
- Do not expose email addresses, tokens, usernames other than your public GitHub name, or private files.
- Keep the MP4 comfortably below GitHub's 100 MB hard Git-object limit; below 25 MB is preferable for visitors.
- Use H.264 video and `+faststart` for easier browser playback.
